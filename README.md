## Cách cài đặt và chạy project

### 1. Yêu cầu
- Trình duyệt hỗ trợ HTML5 (Chrome, Firefox, Edge...)
- Máy tính hoặc server local để chạy file HTML.

### 2. Cài đặt

1. Clone hoặc tải về source code.

```bash
# Clone bằng Git
$ git clone <repository-link>

# Hoặc tải file zip và giải nén
```

2. Cấu trúc thư mục:

```bash
/your-project-folder
|-- index.html            # File HTML chính
|-- /vendor               # Thư viện Bootstrap, jQuery, FontAwesome
|-- /css                  # Tập tin CSS tuỳ chỉnh
|-- /js                   # Tập tin JS tuỳ chỉnh
|-- /img                  # Thư mục chứa hình ảnh
|-- /resume               # Chứa file PDF Resume
```

3. Mở file `index.html` bằng trình duyệt là xem được trang web.
